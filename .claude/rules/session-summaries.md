# Session Summary Writing Rules

- Filename format: `YYYY-MM-DD_kebab-case-description.md`
- Always include frontmatter: Date, Machine, Session ID
- Sections: Context, Tasks, What Was Done, Technologies (at minimum)
- Technical Notes section only when there are genuine challenges or non-obvious details
- Keep summaries under 100 lines — be concise, not exhaustive
- No trailing summaries or "In conclusion" paragraphs
- Preserve non-English terms when they are the natural name for something
- Link to related sessions when a session continues previous work
